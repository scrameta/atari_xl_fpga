# Combined GHDL regression and feature test vectors

Run `bash test/revc/run_combined.sh` **from any directory**, with GHDL supporting VHDL-93 (`--std=93`).

- `baseline_vhdl/`: frozen cleaned Stage 1 VHDL reference.
- `tb_ext_phase.vhd`: directed arithmetic for detuning, stochasticity, overflow, disabled bypass.
- `tb_ext_memory.vhd`: directed packed-RAM writing/reading, logical reset, offset update.
- `cmds_*.txt`: reproducible 6502 command streams generated by `make_feature_vectors.py`.
- `check_audio.py`: reports PCM RMS and differences from the locked baseline (warnings are NOT passes).
- `static_interface_check.py` and `test_reference.py`: Python-only sanity tests.

Full regression criterion is **byte-exact output under locked extensions and with unlocked zero coefficients**. The feature traces are preliminary smoke tests; confirm auditory and spectral behaviour separately.

- `tb_top93.vhd`: VHDL-93 public-interface regression bench (sample, PCM, register reads).
- `check_vhdl93.py`: structural VHDL-93 syntax/style smoke check (not a compiler).

Historical detailed testbenches under `vhdl/tb_*.vhd` still contain
VHDL-2008 external signal names for internal traces. They are not compiled
by `run_combined.sh`; use them separately if you need internal chip/busy traces.
